1.2、以增量运行的方式，统计stocktradetodayinfo当前数据下的各个个股14天的MTR，ATR：
1. 真实波幅（TR / MTR）的公式
这是计算单日波动幅度的基础：
TR = MAX( 当日最高价 - 当日最低价, |当日最高价 - 前一日收盘价|, |当日最低价 - 前一日收盘价| )
2. 14日平均真实波幅（ATR）的公式
ATR是TR的14日指数移动平均（EMA）。计算分为两步：
a) 计算初始ATR（第14天的值）
初始ATR = 过去14个交易日TR值的简单算术平均数
即：ATR(14) = (TR1 + TR2 + ... + TR14) / 14
b) 从第15天开始，使用EMA公式平滑计算
当前ATR = [ 前一日ATR × 13 + 当日TR ] / 14
这是指数移动平均的标准递归公式，确保了新数据权重为1/14，旧数据持续衰减。

一、算法输入与输出

输入参数：

atr_series: pd.Series          # ATR时间序列（带时间索引的pandas Series）
window: int = 20              # 计算变异系数的滚动窗口大小（默认20天）
percentile_threshold: float = 30  # 百分位阈值（默认30%，即低于历史30%分位数定义为"低波动"）
min_stable_days: int = 5     # 最小稳定天数（连续5天才算一个稳定期）
lookback_period: int = 252   # 回溯期（默认一年约252个交易日）

返回值：

返回两个值：
1. stable_periods: List[Dict]  # 稳定时间段列表，每个字典包含一个稳定期的详细信息
2. threshold_series: pd.Series  # 每个时间点对应的动态阈值序列

二、详细算法逻辑

步骤1：计算变异系数（CV）

# 计算滚动窗口的均值和标准差
rolling_mean = atr_series.rolling(window=window).mean()  # 窗口期ATR平均值
rolling_std = atr_series.rolling(window=window).std()    # 窗口期ATR标准差

# 计算变异系数：CV = 标准差 / 均值
# 这个值越小，表示ATR波动越稳定
cv_series = rolling_std / rolling_mean

示例：如果20天内ATR平均为2.5，标准差为0.5，则CV=0.5/2.5=0.2（20%波动率）

步骤2：动态阈值计算（核心逻辑）

dynamic_thresholds = []  # 存储每天的动态阈值
stable_flags = []        # 存储每天是否稳定的标记

for i in range(len(atr_series)):
    if i < lookback_period:  # 前252天，数据不足时
        # 使用已有的历史数据计算百分位数
        available_cv = cv_series.dropna()[:i+1]  # 只使用当前已有的数据
        if len(available_cv) > 0:
            threshold = np.percentile(available_cv, percentile_threshold)
        else:
            threshold = 0.03  # 默认阈值3%
    else:
        # 使用滚动窗口的历史数据（过去252天）
        history_cv = cv_series.iloc[i-lookback_period:i]  # 过去252天的CV
        history_cv = history_cv.dropna()  # 去除NaN
        if len(history_cv) > 0:
            threshold = np.percentile(history_cv, percentile_threshold)
        else:
            threshold = 0.03  # 默认阈值
    
    dynamic_thresholds.append(threshold)
    
    # 判断当天是否稳定（CV值小于阈值，且有足够数据计算CV）
    if i >= window - 1:  # 确保有20天数据计算CV
        current_cv = cv_series.iloc[i]
        stable_flags.append(not pd.isna(current_cv) and current_cv < threshold)
    else:
        stable_flags.append(False)  # 数据不足，标记为不稳定

动态阈值示例：

假设历史CV序列为：[0.15, 0.12, 0.10, 0.08, 0.25, 0.30, ...]
np.percentile(history_cv, 30)计算30%分位数
如果计算结果为0.12，则阈值=0.12
如果当天CV=0.10 < 0.12，则标记为"稳定"

步骤3：识别连续稳定区间

current_start = None  # 当前稳定期的起始索引
stable_periods = []   # 存储所有稳定期

for i, (date, is_stable) in enumerate(zip(stable_flag_series.index, stable_flag_series)):
    if is_stable and current_start is None:
        # 开始一个新的稳定期
        current_start = i
    elif not is_stable and current_start is not None:
        # 稳定期结束，开始计算
        duration = i - current_start  # 持续天数
        
        if duration >= min_stable_days:
            # 记录稳定期信息
            start_date = atr_series.index[current_start]
            end_date = atr_series.index[i-1]
            period_atr = atr_series.iloc[current_start:i]  # 该期间ATR数据
            
            stable_periods.append({
                'start_date': start_date,           # 开始日期
                'end_date': end_date,               # 结束日期
                'duration_days': duration,          # 持续天数
                'avg_atr': period_atr.mean(),       # 期间平均ATR
                'atr_cv': period_atr.std() / period_atr.mean(),  # 期间CV值
                'threshold_used': threshold_series.iloc[current_start:i].mean(),  # 使用阈值的平均值
                'stability_score': 1 - (period_atr.std() / period_atr.mean())  # 稳定性评分（0-1，越高越稳定）
            })
        
        current_start = None  # 重置

五、算法优势与特点

自适应阈值：不是固定阈值（如CV<0.05），而是根据历史数据的分布动态调整


在低波动市场环境中，阈值自动降低（更严格）
在高波动市场环境中，阈值自动升高（更宽松）

百分位逻辑：使用30%分位数意味着：


如果当天CV值低于历史30%的CV值，就认为是"低波动"
这保证了在任何市场环境中，大约有30%的时间会被识别为"稳定"

避免幸存者偏差：只使用历史数据（过去252天），不使用未来数据
渐进式计算：初期数据不足时使用保守估计，数据足够后使用完整历史
