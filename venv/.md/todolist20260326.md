在目录PatternAnalysis\tsanghiapi下（已有），对接股票历史数据日线接口：
get地址：
https://www.tsanghi.com/api/fin/stock/{exchange_code}/daily?token={token}&ticker={ticker}
request示例：
import requests
url = f"https://www.tsanghi.com/api/fin/stock/XSHG/daily?token=demo&ticker=600519"
data = requests.get(url).json()
print(data)

request参数定义：
token
字符串
必选
API Token。登录后获取。
exchange_code
字符串
必选
交易所代码。详见交易所清单接口。

例如：XSHG（上交所）、XSHE（深交所）、XNAS（纳斯达克）。

ticker
字符串
必选
股票代码。详见股票清单接口。

例如：600519（贵州茅台）、AAPL（苹果）。

start_date
日期
可选
起始日期。格式“yyyy-mm-dd”，默认：最近一年。
end_date
日期
可选
终止日期。格式“yyyy-mm-dd”，默认：最新日期。

有两个功能：
1、个股的开始时间和结束时间的历史数据接口，
2、在1的基础上，用mysql的stockinfobase的ts_code作为上述接口的ticker字段（ts_code的数据格式都是类似000001.SZ,需要去掉末尾的.SZ),根据stockinfobase的factory_code作为上述接口地址的exchange_code参数，SZ->XSHE,SH->XSHG。如果返回出错，或者一个股票成功获取数据，都需要记录到日志表（对应的日志配置表的值："id"	"log_code"	"alert_message"	"query_expression"	"created_at"	"updated_at"
