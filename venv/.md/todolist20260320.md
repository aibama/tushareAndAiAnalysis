## 1. 项目概述

本功能通过两级钻取热度图，直观展示中证1000指数成分股的估值/强弱分布。  
- **一级视图（行业层）**：以申万一级行业为维度，展示各行业的综合Z-Score，反映行业内个股偏离自身历史分布的平均状态。  
- **二级视图（个股层）**：点击行业方块后，展示该行业内所有成分股的个股Z-Score，便于定位具体高估/低估标的。  
- **时间序列分析**：支持查看行业或个股最近60个交易日的Z-Score历史走势，辅助趋势判断。

所有Z-Score均采用**滚动60个交易日**的均值和标准差计算，以保证时效性和可比性。

---

## 2. 数据计算逻辑（后端核心）

### 2.1 原始数据准备
- **成分股列表**：中证1000指数成分股，每日更新。
- **股票行情数据**：每日收盘价（用于股价Z-Score）或PE/PB等指标（若需切换）。
- **市值数据**：每日流通市值（用于加权计算）。

### 2.2 个股Z-Score（方法A核心）
对于每个交易日 \( t \) 和每只股票 \( i \)：
1. 取过去60个交易日（含 \( t \)）的指标序列 \( X_{i,t-59}, ..., X_{i,t} \)。
2. 计算均值 \( \mu_{i,t} \) 和标准差 \( \sigma_{i,t} \)。
3. 个股Z-Score：  
   \[
   z_{i,t} = \frac{X_{i,t} - \mu_{i,t}}{\sigma_{i,t}}
   \]
   - 若 \( \sigma_{i,t} = 0 \)（无波动），则 \( z_{i,t} = 0 \)。
   - 缺失数据用前一交易日填充。

### 2.3 行业综合Z-Score
对于每个交易日 \( t \) 和每个行业 \( s \)（申万一级）：
1. 获取该行业当日所有成分股的个股Z-Score \( z_{i,t} \) 及其流通市值 \( w_{i,t} \)。
2. 计算行业综合Z-Score：
   \[
   Z_{s,t} = \frac{\sum_{i \in s} w_{i,t} \cdot z_{i,t}}{\sum_{i \in s} w_{i,t}}
   \]
3. 若行业无成分股，则 \( Z_{s,t} = \text{null} \)。

### 2.4 时间序列数据
- 对于行业：返回该行业过去60个交易日（含当日）的每日 \( Z_{s,t} \) 序列。
- 对于个股：返回该个股过去60个交易日的每日 \( z_{i,t} \) 序列。

## 3. 前端需求

### 3.1 页面布局
- **顶部栏**：标题“中证1000 Z-Score热度图”，更新时间戳（最新交易日），指标切换下拉框（股价/PE/PB，默认股价），日期选择器（默认最新交易日），返回上级按钮（二级视图时显示）。
- **主区域**：热度图（矩形树图或网格布局），自适应画布。
- **右侧边栏（可收缩）**：时间序列分析面板，默认折叠，点击“时序分析”标签展开。
- **悬浮提示（Tooltip）**：鼠标悬停显示详细信息。

### 3.2 一级视图（行业层）
**显示**：
- 每个行业显示为一个矩形（或方格），大小映射该行业成分股数量（或总市值），颜色映射行业综合Z-Score。
- 颜色规则（可配置）：
  - Z-Score ≥ 2：深红
  - 1 ≤ Z-Score < 2：红
  - 0 ≤ Z-Score < 1：浅红
  - -1 ≤ Z-Score < 0：浅绿
  - -2 ≤ Z-Score < -1：绿
  - Z-Score < -2：深绿
  - 无数据：灰色

- **Tooltip** 显示：
  - 行业名称
  - 成分股数量
  - 行业综合Z-Score（保留两位小数）
  - 当日行业加权平均Z-Score的百分位数（基于历史60日分布，可选）

**交互**：
- **悬停**：显示Tooltip，同时时间序列面板（若展开）短暂预览该行业历史曲线（但需鼠标移出后恢复原锁定曲线）。
- **点击**：下钻至该行业的个股二级视图，同时更新URL参数（便于分享），时间序列面板若展开则锁定该行业曲线。
- **右键菜单（可选）**：提供“复制行业数据”或“导出图片”。

### 3.3 二级视图（个股层）
**显示**：
- 展示该行业内所有成分股，每个股票一个矩形（网格布局，按市值排序）。
- 颜色映射个股Z-Score（与一级颜色规则相同）。
- 矩形大小可选：固定大小或按市值比例（后者可能造成过大差异，建议固定大小并支持缩放）。

- **Tooltip** 显示：
  - 股票名称、代码
  - 流通市值
  - 个股Z-Score
  - 当日股价（或所选指标值）

**交互**：
- **悬停**：显示Tooltip，时间序列面板预览该个股历史曲线。
- **点击**：右侧可展开个股详情（如K线图、财务数据），或在时间序列面板锁定该个股曲线。
- **返回**：点击顶部“返回行业全景”按钮，回到一级视图，保留时间序列面板的锁定状态（若原锁定为个股，返回后应自动切换为当前行业的曲线，避免歧义）。

### 3.4 时间序列面板
**组件**：
- 折线图，横轴为日期（最近60个交易日），纵轴为Z-Score值。
- 辅助线：0轴（实线），±1、±2（虚线）。
- 鼠标悬停显示具体数值和日期。
- 支持缩放（鼠标滚轮）和平移（拖拽）。
- 右上角有“导出图片”按钮。

**数据联动**：
- 面板展开时，默认显示中证1000整体Z-Score（由全部个股加权平均计算，方法同行业）。
- 当用户**悬停**行业或个股时，曲线短暂切换（预览模式），鼠标移出后恢复锁定曲线。
- 当用户**点击**行业或个股时，曲线锁定为该实体（行业或个股）的历史曲线。
- 在二级视图点击“返回行业全景”后，若当前锁定的是个股曲线，则自动切换为该行业的曲线。
- 用户可在面板下拉菜单中手动切换实体（行业或个股），且不受主视图点击影响。

### 3.5 指标切换与日期选择
- **指标切换**：下拉菜单（股价、PE、PB等）。切换后，后端重新返回新指标下的Z-Score数据，前端更新所有方块颜色及时间序列曲线。
- **日期选择**：用户可选择历史交易日，查看当时的热度图。热度图数据及时间序列曲线均相应更新。注意：日期选择后，时间序列面板显示的曲线应以该日期为最后一天，展示该日期之前的60个交易日数据。

## 4. 后端需求

### 4.1 接口设计
**基础URL**：`/api/v1/zscore`

#### 4.1.1 获取行业列表及当日Z-Score
- **端点**：`GET /industry/daily`
- **参数**：
  - `date`：日期（YYYY-MM-DD），可选，默认最新交易日。
  - `indicator`：指标类型（`price`、`pe`、`pb`），默认`price`。
- **响应**：
```json
{
  "code": 0,
  "data": {
    "date": "2026-03-20",
    "industries": [
      {
        "industry_code": "801010",
        "industry_name": "电子",
        "stock_count": 85,
        "total_mv": 123456789.0,
        "zscore": 0.85,
        "zscore_percentile": 75.2
      },
      ...
    ]
  }
}
```

#### 4.1.2 获取某行业下成分股及当日Z-Score
- **端点**：`GET /industry/stocks`
- **参数**：
  - `date`：日期
  - `indicator`：指标类型
  - `industry_code`：行业代码
- **响应**：
```json
{
  "code": 0,
  "data": {
    "date": "2026-03-20",
    "industry_name": "电子",
    "stocks": [
      {
        "stock_code": "000001",
        "stock_name": "平安银行",
        "mv": 12345678.9,
        "zscore": 1.23,
        "indicator_value": 12.34
      },
      ...
    ]
  }
}
```

#### 4.1.3 获取时间序列（行业或个股）
- **端点**：`GET /timeseries`
- **参数**：
  - `date`：结束日期（YYYY-MM-DD），必填。
  - `indicator`：指标类型。
  - `entity_type`：`industry` 或 `stock`。
  - `entity_code`：行业代码或股票代码。
  - `days`：回溯天数，默认60。
- **响应**：
```json
{
  "code": 0,
  "data": {
    "entity_name": "电子",
    "entity_type": "industry",
    "indicator": "price",
    "series": [
      { "date": "2026-01-01", "zscore": 0.5 },
      { "date": "2026-01-02", "zscore": 0.6 },
      ...
    ]
  }
}
```

#### 4.1.4 获取中证1000整体Z-Score时间序列（用于面板默认）
- **端点**：`GET /index/timeseries`
- 参数同上，`entity_type=index`。
- 响应结构与4.1.3类似。

### 4.2 数据处理要求
- **定时任务**：每日收盘后，计算所有成分股的个股Z-Score、行业综合Z-Score，存入数据库（表结构建议分区，按日期）。
- **实时查询**：接口直接读取预计算表，避免实时计算压力。
- **指标切换**：若支持PE/PB，需存储对应的历史序列，计算逻辑相同。
- **缓存**：对历史固定日期的数据，可设置Redis缓存，有效期1天。

### 4.3 异常处理
- 若某股票上市不足60个交易日，则从上市日算起，历史数据不足时Z-Score为null（不参与行业加权）。
- 行业无有效成分股时，Z-Score返回null，前端显示灰色。
- 返回的数据中，缺失Z-Score的股票或行业不应出现在列表中（或标注为无效）。
