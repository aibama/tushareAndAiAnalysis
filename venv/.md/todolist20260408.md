# A股涨跌停判断服务（含精度处理）
1. 核心规则
A股涨跌停板价格的官方计算规则如下：

涨停价 = round(前收盘价 × (1 + 涨停比例), 2)

跌停价 = round(前收盘价 × (1 - 跌停比例), 2)

其中 round(..., 2) 表示四舍五入保留两位小数（即精确到“分”）。第三位小数采用普通四舍五入（0.005 向上入）。

判断标准：

若今日收盘价 ≥ 涨停价（考虑极小精度误差），则判定为“涨停”。

若今日收盘价 ≤ 跌停价（考虑极小精度误差），则判定为“跌停”。

否则为“正常”。

注意：触及涨停/跌停不代表全天封死，但算法只判断价格是否达到边界。

2. 涨跌幅限制比例
板块类型	涨停比例	跌停比例	说明
主板普通股	+10%	-10%	600/000/002/003 开头
主板 ST / *ST 股	+5%	-5%	风险警示板
科创板（688开头）	+20%	-20%	
创业板（300/301开头）	+20%	-20%	
北交所（8开头）	+30%	-30%	
新股上市首日	特殊规则	特殊规则	不在此通用算法内，可扩展参数
注：算法中 limit_rate 参数应传入小数形式（如 0.10 表示 10%）。

3. 程序性步骤
输入参数

prev_close：前一日收盘价（单位：元，浮点数）

close：今日收盘价（单位：元，浮点数）

limit_rate：涨跌停幅度（如 0.10）

有效性校验

若 prev_close == 0，抛出异常或返回错误（避免除零及无效计算）。

计算理论涨跌停价（严格四舍五入到分）

limit_up_price = round(prev_close * (1 + limit_rate), 2)

limit_down_price = round(prev_close * (1 - limit_rate), 2)

精度容差处理

由于浮点数运算可能产生极小误差（如 10.06 - 10.06 = 1.776e-15），设置容差 eps = 1e-6（或使用 Decimal 精确比较）。

比较并返回结果

close >= limit_up_price - eps → 涨停

close <= limit_down_price + eps → 跌停

其他 → 正常

def round_to_two_decimals(value: float) -> float:
    """普通四舍五入保留两位小数（第三位四舍五入）"""
    return round(value, 2)

def check_limit_status(prev_close: float, close: float, limit_rate: float) -> dict:
    """
    判断今日收盘价是否触及涨跌停板

    Args:
        prev_close: 前一日收盘价
        close:      今日收盘价
        limit_rate: 涨跌停幅度（0.10 表示 ±10%）

    Returns:
        dict: {
            "status": "涨停"/"跌停"/"正常",
            "limit_up_price": 涨停价,
            "limit_down_price": 跌停价,
            "is_limit": bool
        }
    """
    if prev_close == 0:
        raise ValueError("前收盘价不能为0")

    limit_up_price = round_to_two_decimals(prev_close * (1 + limit_rate))
    limit_down_price = round_to_two_decimals(prev_close * (1 - limit_rate))

    eps = 1e-6
    if close >= limit_up_price - eps:
        return {
            "status": "涨停",
            "limit_up_price": limit_up_price,
            "limit_down_price": limit_down_price,
            "is_limit": True
        }
    elif close <= limit_down_price + eps:
        return {
            "status": "跌停",
            "limit_up_price": limit_up_price,
            "limit_down_price": limit_down_price,
            "is_limit": True
        }
    else:
        return {
            "status": "正常",
            "limit_up_price": limit_up_price,
            "limit_down_price": limit_down_price,
            "is_limit": False
        }
